# hirunogohan-templates

## リポジトリの説明
競技プログラミングなど用のテンプレートなど

## テンプレート一覧
- start：最初に書くやつ
- BFS（グラフ）：グラフでのBFS（最短距離）
- BFS（グリッド）：グリッドでのBFS（最短距離）
- セグメント木：一点での編集ができるセグメント木
    - update：セグ木の更新(1点)
        - 入力: I = 更新するindex, X = 新しい値
        - 計算量: O(log N)
    - switch：セグ木の更新(交換)
        - 入力: I, J = 交換する2つのindex
        - 計算量: O(log N)
    - queryindex：indexを入手
        - 入力: X = 探したい値
        - 計算量: O(1) ※値が重複しない場合。重複ありは同じ値の個数分
    - querysum：合計値を入手
        - 入力: L = 左端(含む), R = 右端(含まない)
        - 計算量: O(log N)
    - querymax：最大値を入手
        - 入力: L = 左端(含む), R = 右端(含まない)
        - 計算量: O(log N)
    - querymin：最小値を入手
        - 入力: L = 左端(含む), R = 右端(含まない)
        - 計算量: O(log N)
- 遅延セグメント木：区間での編集ができるセグメント木
    - 普通のセグ木 +a
    - add：セグ木の更新(区間加算)
        - 入力: L = 左端(含む), R = 右端(含まない), X = 加算する値
        - 計算量: O(log N + (R-L)) ※A/Hの同期処理を含む
    - set：セグ木の更新(区間代入)
        - 入力: L = 左端(含む), R = 右端(含まない), X = 新しい値
        - 計算量: O(log N + (R-L)) ※A/Hの同期処理を含む
- Union-Find：グループの結合と、同じグループかどうかの判定ができるデータ構造
    - 初期化：N 個の要素をそれぞれ別グループにする
        - 入力: N = 要素数
        - 計算量: O(N)
    - find：根を探す(経路圧縮あり)
        - 入力: I = 根を探したい要素
        - 計算量: 償却 O(α(N)) ≒ O(1)
    - same：同じグループか判定する
        - 入力: I, J = 判定する2つの要素
        - 計算量: 償却 O(α(N)) ≒ O(1)
    - union：グループを結合する(サイズの小さい方を大きい方につなぐ)。結合したら True、元々同じなら False
        - 入力: I, J = 結合する2つの要素
        - 計算量: 償却 O(α(N)) ≒ O(1)
    - isroot：根か判定する
        - 入力: I = 判定する要素
        - 計算量: O(1)
    - querysize：グループの要素数を入手
        - 入力: I = 調べたい要素
        - 計算量: 償却 O(α(N)) ≒ O(1)
    - querygroups：グループ数を入手
        - 入力: なし
        - 計算量: O(1)
    - querymaxsize：最大グループの要素数を入手
        - 入力: なし
        - 計算量: O(1)
    - querymembers：Iが属するグループの全要素を入手
        - 入力: I = 調べたい要素
        - 計算量: O(N α(N))
    - queryroots：全グループの根を入手
        - 入力: なし
        - 計算量: O(N α(N))
    - queryall：全グループを入手 [[グループ1の要素], [グループ2の要素], ...]
        - 入力: なし
        - 計算量: O(N α(N))
    - reset：初期状態(全要素が別グループ)に戻す
        - 入力: なし
        - 計算量: O(N)
